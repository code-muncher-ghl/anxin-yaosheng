业务流程

一次「拍照 → 听懂 → 问明白」的完整链路

绿色为 AI 环节，橙色为安全干预点，深色为用户价值交付

STEP 1
老人拍说明书
子女也可代传
相册/拍照/粘贴文字
→
STEP 2 · VLM
结构化解析
11 字段 + 原文证据
不确定就返回 null
→
STEP 3 · 门禁
置信度判断
低于 0.75 提示重拍
或转药师人工
→
STEP 4 · LLM
生成播报稿
四段式、每句≤20字
数字白名单校验
→
STEP 5 · TTS
慢速语音
数字转中文读法
语速 -12%
→
STEP 6
听懂说明书
可以反复听
可以随时追问
Q1
老人追问
「饭前还是饭后？」
「能和降压药一起吃吗？」
→
Q2 · Agent
决定调哪个工具
Function Calling
检索 / 相互作用 / 常识
→
Q3 · RAG
召回证据
BM25 + 章节先验
每条证据带编号
→
Q4 · LLM
有据生成
只用证据回答
必须标注 [编号]
→
Q5 · 护栏
四道闸门
数字接地/引用/危险建议
+ 独立 Verifier 复核
→
Q6
可信回答
不确定就说不确定
危险问题转医生

闸门 ①：数字接地

答案里的每个「数字+单位」必须能在证据原文中找到，否则整段降级

闸门 ②：引用校验

[n] 必须落在召回编号范围内，杜绝「编一条参考文献」

闸门 ③：危险建议拦截

停药/换药/加量/诊断 → 强制改写为「请医生判断」

闸门 ④：独立复核

另起一次模型调用逐句核对，不通过则回退保守答案

闭环升级
加入用药清单 → 多药冲突分级（禁忌/严重/注意） → 相互作用知识库命中 → 生成家属交接单 → 药师人工复核（高风险）
